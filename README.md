### 🚀 Repository Structure

Each folder is organized by problem set or contest ID to keep things clean:

* 📂 **Contests/** - Live contest solutions (Div. 2, Div. 3, Edu).
* 📂 **Problemset/** - Practice problems sorted by difficulty/tags.
* 📂 **Templates/** - Reusable C++/Kotlin/Java snippets for fast coding.
